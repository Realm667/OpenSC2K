# Reticulating Splines application icon

The RS city icon was commissioned by Daniel for this remaster and generated
with OpenAI image generation. This is the approved software-icon v1 artwork;
the PNG and multi-resolution Windows ICO share the same source.

The Windows exports use `ReticulatingSplines.exe` (x86_64) and
`ReticulatingSplines-arm64.exe`. Their external PCK files use matching names.
The application configuration name remains unchanged to preserve existing
non-portable user profiles. Original OpenSC2K attribution and licenses remain.
